# Code of conduct

Stampede follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep discussion about the work,
and do not harass anyone. Maintainers may remove comments, commits or
contributors that break these rules.

Report conduct problems privately to the maintainers through a GitHub
security advisory on this repository (Security → Report a vulnerability),
marking it as a conduct report. Reports are handled confidentially.
