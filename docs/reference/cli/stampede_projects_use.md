## stampede projects use

Set the default project for commands given no --project

### Synopsis

Store a default project in the config file, used by every command that
takes --project when the flag is left out. STAMPEDE_PROJECT overrides it.
--clear removes it.

```
stampede projects use [project] [flags]
```

### Options

```
      --clear   remove the default project
  -h, --help    help for use
```
