## stampede drift results

List the results of a project's scheduled drift checks, newest first

```
stampede drift results [flags]
```

### Options

```
  -h, --help              help for results
      --json              print JSON for scripting
      --limit int         how many results (at most 200) (default 50)
      --project string    project name, slug or id (default: the default or only project)
      --schedule string   only the checks of this schedule
```
