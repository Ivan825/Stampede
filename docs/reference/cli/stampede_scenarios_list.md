## stampede scenarios list

List a project's scenarios with their latest version

```
stampede scenarios list [flags]
```

### Options

```
  -h, --help         help for list
      --json         print JSON for scripting
      --tag string   only scenarios with this tag
```

### Options inherited from parent commands

```
      --project string   project name, slug or id (default: the default or only project)
```
