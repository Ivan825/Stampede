## stampede caps

Show or set the organisation's hard caps on every run

### Synopsis

Every run in the organisation must fit within these caps, as well as the
server's, its project's and its target's (stampede settings limits shows
them all). Setting them needs the admin role and is audited.

### Options

```
  -h, --help   help for caps
```
