## stampede projects roles

Give members a different role in one project

### Synopsis

A member's organisation role applies in every project unless an override
sets another role, higher or lower, for one project. Owners are owners
everywhere. Changing overrides needs the admin role in the project.

### Options

```
  -h, --help             help for roles
      --project string   project name, slug or id (default: the default or only project)
```
