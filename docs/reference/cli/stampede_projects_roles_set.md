## stampede projects roles set

Give a member a role in this project (admin)

```
stampede projects roles set <user> <role> [flags]
```

### Examples

```
  stampede projects roles set pat@acme.test viewer --project shop
```

### Options

```
  -h, --help   help for set
```

### Options inherited from parent commands

```
      --project string   project name, slug or id (default: the default or only project)
```
