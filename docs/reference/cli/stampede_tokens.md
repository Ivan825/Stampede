## stampede tokens

List, create and revoke your API tokens

### Synopsis

API tokens let scripts and CI use the API as you, with your role or a
lower one: set STAMPEDE_SERVER and STAMPEDE_TOKEN. A token's secret is
shown once, when it is created, and never again. Tokens are named by
name, id or prefix.

### Options

```
  -h, --help   help for tokens
```
