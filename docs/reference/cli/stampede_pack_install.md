## stampede pack install

Copy a pack's journeys, stresses, targets and data into a folder

```
stampede pack install <pack> [flags]
```

### Options

```
      --dir string   destination folder (default "stampede")
      --force        overwrite files that already exist
  -h, --help         help for install
```
