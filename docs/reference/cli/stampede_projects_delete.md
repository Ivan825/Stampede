## stampede projects delete

Delete a project with everything in it

### Synopsis

Delete a project together with its targets, scenarios, runs, reports,
schedules and secrets. This cannot be undone, so it needs --yes.

```
stampede projects delete <project> [flags]
```

### Options

```
  -h, --help   help for delete
      --yes    confirm the deletion
```
