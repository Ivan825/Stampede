## stampede password

Change your password

### Synopsis

Change the password you sign in with. Asks for the current and the new
password without echo, or reads them from STAMPEDE_PASSWORD and
STAMPEDE_NEW_PASSWORD. Your other browser sessions are signed out; API
tokens keep working.

```
stampede password [flags]
```

### Options

```
  -h, --help   help for password
```
