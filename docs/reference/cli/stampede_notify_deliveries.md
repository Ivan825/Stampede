## stampede notify deliveries

List a channel's most recent delivery attempts, newest first

```
stampede notify deliveries <channel> [flags]
```

### Options

```
  -h, --help        help for deliveries
      --json        print JSON for scripting
      --limit int   how many attempts (at most 50) (default 50)
```
