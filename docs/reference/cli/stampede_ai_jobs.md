## stampede ai jobs

Start, follow and approve AI journey generation jobs

### Synopsis

A job understands its inputs, drafts a scenario, checks it, dry-runs each
journey once with one user against the target and repairs failures. Its
result is a proposal: approve it to save it as a new scenario or a new
version. Jobs are named by id or a unique start of it.

### Options

```
  -h, --help             help for jobs
      --project string   project name, slug or id (default: the default or only project)
```
