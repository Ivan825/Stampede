## stampede projects create

Create a project

```
stampede projects create <name> [flags]
```

### Examples

```
  stampede projects create Shop --description "The storefront and its API" --use
```

### Options

```
      --description string   what the project tests
  -h, --help                 help for create
      --json                 print JSON for scripting
      --use                  make it the default project (stampede projects use)
```
