## stampede pack test

Dry-run every journey of a pack once against a target

```
stampede pack test <pack or folder> [flags]
```

### Options

```
  -e, --env stringArray   KEY=VALUE (repeatable)
  -h, --help              help for test
      --target string     target base URL (sets TARGET_URL)
```
