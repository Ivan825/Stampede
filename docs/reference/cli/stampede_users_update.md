## stampede users update

Rename a member or change their role

```
stampede users update <user> [flags]
```

### Examples

```
  stampede users update pat@acme.test --role admin
```

### Options

```
  -h, --help          help for update
      --json          print JSON for scripting
      --name string   new name
      --role string   new role: owner, admin, editor, runner or viewer
```
